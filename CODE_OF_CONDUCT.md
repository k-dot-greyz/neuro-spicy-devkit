# Code of Conduct

## The Short Version

Be kind. Be direct. Be patient. We're all here because brains are weird and code is fun.

## The Longer Version

This project exists to make development more accessible for neurodivergent developers. We take that mission seriously by creating a space where everyone can contribute without masking, scripting social interactions, or burning energy on unwritten rules.

### We value

- **Clarity over politeness theater** — Say what you mean. Skip the fluff. Direct communication isn't rude, it's accessible.
- **Patience with different processing speeds** — Some of us need time to context-switch. Some of us hyperfocus and forget to respond. Both are fine.
- **Multiple communication styles** — Bullet points, walls of text, voice notes, diagrams, memes — whatever gets the idea across.
- **Asking questions** — There are no stupid questions. If the docs don't answer it, the docs need fixing.
- **Stimming, humor, and being yourself** — Spicy humor, dark jokes, playful sarcasm? Welcome. Just don't punch down.

### We don't tolerate

- Harassment, bullying, or discrimination of any kind
- Deliberate intimidation or gatekeeping
- Dismissing someone's experience ("just focus harder", "have you tried not being anxious")
- Publishing others' private information
- Weaponizing someone's neurodivergence against them

### Enforcement

Violations can be reported to [@k-dot-greyz](https://github.com/k-dot-greyz) via DM or email. Reports are handled confidentially.

- **First offense**: Private conversation
- **Pattern of behavior**: Temporary ban from project spaces
- **Severe or repeated violations**: Permanent ban
